# Audio Demo File Attribution

This directory contains short, public-domain (or freely licensed) audio snippets used
by the SmarkForm `audio` component documentation examples and tests.

## Included files

### `audio_beethoven_5th.mp3`

- **Piece:** Ludwig van Beethoven — Symphony No. 5 in C minor, Op. 67, 1st movement: *Allegro con brio*
- **Source:** Wikimedia Commons, file: [`Ludwig van Beethoven - Symphonie 5 c-moll - 1. Allegro con brio.ogg`](https://commons.wikimedia.org/wiki/File:Ludwig_van_Beethoven_-_Symphonie_5_c-moll_-_1._Allegro_con_brio.ogg)
- **Original download URL:**  
  `https://upload.wikimedia.org/wikipedia/commons/5/5b/Ludwig_van_Beethoven_-_Symphonie_5_c-moll_-_1._Allegro_con_brio.ogg`
- **Composer:** Ludwig van Beethoven (1770–1827) — original work is in the public domain.
- **Performance / recording:** Fulda Symphonic Orchestra, conducted by Simon Schindler (recorded 10 March 2002).
- **License:** The original composition is public domain. The recording was released under the EFF Open Audio License 1.0 and is marked with the Creative Commons Public Domain Mark. It may be copied, redistributed, performed, or modified for use in these documentation examples.
- **Note:** The file bundled here is a short 25-second excerpt created by trimming the first ~25 seconds and re-encoding to MP3. This smaller clip keeps the documentation examples fast to load while still being immediately recognizable.

### `audio_moonlight_sonata.mp3`

- **Piece:** Ludwig van Beethoven — Piano Sonata No. 14 in C♯ minor, Op. 27, No. 2, 1st movement (commonly known as *Moonlight Sonata*, *Quasi una fantasia*)
- **Source:** Wikimedia Commons, file: [`Beethoven Sonate n14 1er mvt.wav`](https://commons.wikimedia.org/wiki/File:Beethoven_Sonate_n14_1er_mvt.wav)
- **Original download URL:**  
  `https://upload.wikimedia.org/wikipedia/commons/9/97/Beethoven_Sonate_n14_1er_mvt.wav`
- **Composer:** Ludwig van Beethoven (1770–1827) — original work is in the public domain.
- **Performance / recording:** Dorian Pâquet (performed June–July 2016 on a 2006 Chavanne piano), contributed to Commons by Hérisson grognon.
- **License:** The original composition is public domain. The recording is licensed under Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0). See the source page for full attribution details.
- **Note:** The file bundled here is a short 25-second excerpt created by trimming the opening and re-encoding to MP3.

## General notes

- Both clips are kept small (MP3, ~160–320 kB, ~25 seconds) so they load quickly in the live documentation examples and do not bloat exports during interactive testing.
- The snippets are used only to demonstrate the SmarkForm `audio` field type. No endorsement by the performers or uploaders is implied.
- Thank you to the Wikimedia Commons contributors, the Fulda Symphonic Orchestra, Simon Schindler, and Dorian Pâquet for making these recordings freely available.
